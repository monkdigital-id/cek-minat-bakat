# Cek Minat Bakat

Survei refleksi singkat (24 pernyataan) untuk mengenali kecenderungan minat dan bakat berdasarkan 8 jenis kecerdasan menurut teori Kecerdasan Majemuk Howard Gardner: Linguistik, Logis-matematis, Visual-spasial, Musikal, Kinestetik-tubuh, Interpersonal, Intrapersonal, dan Naturalis.

- Kelompok usia: Balita (0–5), Anak SD (6–12), Remaja (13–17) diisi orang tua; Dewasa (18+) diisi sendiri.
- Hasil berupa profil 8 kecerdasan, 3 kecerdasan teratas beserta cara mengasahnya, tokoh inspiratif, dan daftar rujukan akademik.
- Satu file `index.html`, tanpa backend; semua dihitung di browser, tidak ada data yang disimpan atau dikirim.
- Hasil adalah alat refleksi, bukan tes psikologi atau tes IQ.
